# 0.3.0：补全历史用量

发布版本：`@geecraft23/dsh-token-usage@0.3.0`。

旧版只记录插件运行期间的新请求。0.3 增加「补全历史用量」：扫描 DSH 已保存的会话，预览后导入真实用量，让活动图、模型明细、本地／云端统计和 JSON 导出覆盖可恢复的旧记录。

- 重复导入、重启和再次扫描均保留去重身份；已有实时记录只在可靠匹配时关联。
- 支持取消后继续；显示缺失用量、读取失败和无法确定的重叠项。
- 延续已有部署分类、90／30 天活动图和 K／M／B 数值显示。
- 首次升级前自动备份旧账本，再迁移至版本 2；共用账本的 Profile 需要一起升级。

验证：44 项测试、类型检查、构建、真实历史副本独立对账、安装包 Profile 与合成记录导入。没有保存的用量无法精确恢复，详见 [统计口径](accounting.zh-CN.md)。npm 安装验证结果记录在对应的 GitHub Release 中。
